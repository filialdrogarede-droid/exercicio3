# Conceitos de Segurança

## Vulnerabilidade
Fraqueza que pode ser explorada.

## Ameaça
Agente capaz de explorar uma vulnerabilidade.

## Risco
Probabilidade x impacto.

## Tríade CIA

### Confidencialidade
Proteção contra acesso não autorizado.

### Integridade
Garantia de que os dados não foram alterados.

### Disponibilidade
Garantir acesso quando necessário.
